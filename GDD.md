🐍 GAME DESIGN DOCUMENT — Snake (Unity)
Версия: 1.0 (релиз MVP)
Дата: 2025
Платформа: PC (Windows / Mac / Linux)
Движок: Unity 2022.3 LTS
Язык: C#
Жанр: Arcade / Casual
Режим: Single-player
Длительность сессии: 2–10 минут
________________________________________
1. OVERVIEW / Обзор
1.1 Concept
Классическая аркадная змейка: игрок управляет змеёй на поле 20×20, собирает еду, растёт, ускоряется и старается не врезаться в стены или в собственный хвост. Цель — набрать максимальный счёт и побить личный рекорд.
1.2 Core Experience
•	Мгновенный отклик на ввод (Input buffering).
•	Постепенный рост напряжения: чем длиннее змейка, тем сложнее маневрировать.
•	Удовольствие от «почти попал» и точных поворотов.
•	Быстрые сессии, идеально подходящие «на перерыв».
1.3 Target Audience
Казуальные игроки, любители аркад и retro-игр, все возрасты. Управление простое — доступно даже новичкам.
1.4 Unique Selling Points
•	Плавное движение сегментов за счёт интерполяции (в отличие от резкой телепортации в классике).
•	Input buffering — нажатия обрабатываются заранее, снижая «фрустрацию» от неточных поворотов.
•	Прогрессирующая скорость — каждые 5 яблок игра ускоряется.
•	Локальный рекорд (PlayerPrefs) сохраняется между сессиями.

2. GAMEPLAY / Геймплей
2.1 Game Loop
1.	Игрок запускает сцену MainMenu, выбирает PLAY.
2.	Загружается Game — змейка длиной 3 сегмента появляется в центре поля.
3.	Игрок двигается WASD / стрелками.
4.	Съедая яблоко — рост +1 сегмент, счёт +1, звук «eat».
5.	Каждые 5 яблок скорость увеличивается на 0.005 с (до минимума 0.07 с).
6.	Врезается в стену или хвост → Game Over.
7.	Появляется Game Over Panel с финальным счётом и рекордом.
8.	Игрок жмёт RESTART / MENU.
2.2 Управление
Платформа	Действие	Клавиша
PC	Движение вверх	W / ↑
PC	Движение вниз	S / ↓
PC	Влево	A / ←
PC	Вправо	D / →
PC	Пауза	Esc
Управление реализовано через Unity Input System (New) с Action Maps: Gameplay (движение) и UI (пауза, всегда активна).
2.3 Правила
•	Поле: 20×20 клеток, 1 клетка = 1 юнит.
•	Змейка движется по сетке (grid-based), шаг = 1 клетка за тик.
•	Стартовый интервал шага: 0.15 с, минимум 0.07 с.
•	Начальная длина: 3 сегмента, старт в центре (10, 10).
•	Одновременно на поле — 1 яблоко на случайной свободной клетке.
•	Разворот на 180° запрещён — нажатие игнорируется.
•	Ввод буферизуется: можно задать следующий поворот до тика.
2.4 Win / Lose
Lose:
•	Столкновение со стеной (выход за границы поля).
•	Столкновение с собственным телом.
Win:
•	Отсутствует (endless-режим). Прогрессия выражается через счёт и рекорд.

3. MECHANICS / Механики (детально)
Механика	Описание
Движение	Grid-based, с интерполяцией позиций сегментов между клетками
Хранение змейки	List<Vector2Int> клеток + List<Transform> визуальных сегментов. [0] — всегда голова
Рост	При поедании яблока хвост не удаляется, добавляется новый сегмент
Еда	Спавн на случайной свободной клетке (до 500 попыток)
Счёт	+1 за яблоко. Отображается в HUD в реальном времени
Рекорд	Сохраняется в PlayerPrefs под ключом BestScore
Ускорение	Каждые 5 яблок stepInterval -= 0.005 с, минимум 0.07 с
Пауза	Time.timeScale = 0, Gameplay Action Map отключается
Game Over	Змейка скрывается, звук смерти, панель с финальным счётом
Рестарт	Перезагрузка активной сцены через SceneManager
Возврат в меню	Загрузка сцены MainMenu

4. PROGRESSION / Прогрессия
•	Локальная прогрессия: только рекорд (PlayerPrefs).
•	Нет системы уровней, апгрейдов, скинов.
•	Сложность нарастает автоматически через ускорение и рост длины.

5. ART & AUDIO / Арт и звук
5.1 Визуальный стиль
•	Пиксель-арт, спрайты 16×16 px.
•	Filter Mode: Point (no filter) — резкие пиксели.
•	Pixels Per Unit: 16 → 1 спрайт = 1 клетка.
•	Палитра: 4–6 цветов (зелёный, красный, серый, чёрный, белый).
5.2 Спрайты

SnakeBody.png	Сегмент тела змейки
SnakeHead.png	Голова (с глазами)
Food.png	Яблоко
Wall.png	Кирпич для рамки поля
5.3 UI
•	Шрифт: TextMeshPro (SDF).
•	HUD: счёт в верхнем левом углу.
•	Меню, пауза, Game Over — текст + кнопки на Canvas.
5.4 Звук
Событие	Файл	Тип
Съедание яблока	eat.wav	Короткий «бип»
Смерть	death.wav	Низкий тон
Клик по кнопке	click.wav	Тихий щелчок

Звук управляется через синглтон AudioManager с DontDestroyOnLoad — музыка играет непрерывно между сценами.

7. TECHNICAL / Техническая часть (Unity)
7.1 Сцены
•	MainMenu.unity — меню.
•	Game.unity — игровой процесс.
Build Settings: MainMenu (index 0), Game (index 1).
7.2 Ключевые скрипты
Скрипт	Ответственность
GridManager	Сетка, перевод клетка ↔ мир, границы
GameManager	Счёт, рекорд, состояние игры, Game Over Panel
AudioManager	SFX + музыка, синглтон через сцены
PauseManager	Пауза, Time.timeScale, UI-панель
SnakeController	Движение, рост, коллизии, интерполяция
FoodSpawner	Спавн еды, проверка поедания
WallBuilder	Генерация визуальных стен по периметру
InputHandler	Чтение Input Actions, буферизация ввода
MainMenu	Обработка кнопок меню
ButtonClickSound	Звук клика на каждой кнопке
SnakeControls (gen)	Авто-сгенерированный класс Input Actions
7.3 Архитектурные решения
Синглтоны: GridManager, GameManager, AudioManager, FoodSpawner, PauseManager — доступ через Instance.
Хранение змейки:
•	_cells: List<Vector2Int> — логические позиции.
•	_segments: List<Transform> — визуальные сегменты.
•	Индекс 0 — всегда голова. При шаге Insert(0, newHead).
Тик-система: аккумулятор в Update(), шаг по stepInterval. Не зависит от FPS.
Input buffering: _queuedDirection — отложенный поворот применяется на следующем тике.
Интерполяция: Vector3.Lerp с экспоненциальным сглаживанием 1 - exp(-20 * dt).
Коллизии: ручная проверка клеток (без физики) — O(n), где n — длина змейки.
7.4 Производительность
•	Целевой FPS: 60.
•	Object pooling не применяется (малые объёмы), но возможен как оптимизация.
•	Нет аллокаций в горячем цикле (использование List, переиспользование).
7.5 Сохранения
•	PlayerPrefs — BestScore, потенциально — настройки звука.
•	Кроссплатформенно, работает на Windows / Mac / Linux / Mobile.

9. POST-LAUNCH / Идеи для развития

•	Поле с башнями; змейка — защитник, турели ставятся на клетки.

•	Перки при поедании (ускорение, проходимость через хвост, телепорт).
•	Случайные препятствия / биомы / боссы.
•	Апгрейды между сессиями.
